摸鱼桌宠 —— 使用说明
====================

一、怎么启动
------------

双击这个文件即可：

  摸鱼桌宠-win32-x64\摸鱼桌宠.exe

文件夹里有 48 张立绘和运行库，别单独把 exe 拷出来 ——
它需要同目录的 resources 文件夹才能跑。

想放桌面方便点：右键 exe → 发送到 → 桌面快捷方式。

启动后会出现两样东西：
  · 屏幕右下角的悬浮 Yuki（桌宠本体）
  · 系统托盘区的小图标（右键有菜单）

关闭面板窗口不会退出程序，桌宠和托盘还在。
想彻底退出：右键桌宠 → 退出摸鱼桌宠（她会先挥手告别）。


二、桌宠怎么用
--------------

Yuki 会回应你的操作，不同动作有不同反应，而且表情会跟着变：

· 鼠标悬停     停 1 秒左右，她比个心跟你说句话
· 单击         回你一句；连点太快她会鼓腮生气「摸一次够啦」
· 双击         吓一跳
· 长按 0.7 秒  害羞地捂脸，贴贴
· 拖动         按住左键拖走，放下后无奈摊手
· 双击气泡     立即刷新数据
· 右键         弹出完整功能菜单，见下

她还会自己找话说：

· 挂机一段时间会主动冒一句话（间隔可调，详见设置）
· 有两种内容混着说：结合你们最近的聊天内容，或者从台词库挑一句
  —— 前者只参考最近两天聊过的，不会翻出几周前的旧事
· 分得清谁说的，她会追问你说过的事，不会拿自己说过的话来问你
· 早上、刚上班、快下班、下班、休息日各有不同的话和表情
· 工作中每隔 50 分钟提醒你起来动一动

### 她的动作会越来越多

挂机时她会自己在旁边做各种事（吃零食、戴耳机、发呆、打哈欠……），
而且这些动作随着亲密度解锁：

  有点眼熟     4 种动作
  熟络起来了   7 种
  好朋友       10 种
  默契搭档     14 种
  形影不离     15 种

刚认识时她比较收敛，关系越好越放松 —— 你能明显看出来她变了。

另外 4 个动作只在特定时候出现：生气（连点她 4 次）、挥手（退出前）、
竖大拇指（打卡成功）、举手（补卡成功）。

### 换装

她一共有 24 套衣服：

  日常         JK 制服、红外套、荷边裙、黑白裙、深色制服
  睡衣         睡裙、黑吊带、粉吊带、连体衣、短睡裙
  清爽         吊带、长裙、旗袍
  校园与特色    清纯校园、校园偶像、偶像风格、女仆、修女
  冬日与正式    圣诞装、新年旗袍、礼服、西装、风衣、泳装

穿什么由时间决定（默认）：

  23:00 - 07:00   睡衣
  07:00 - 09:00   居家清凉
  21:00 - 23:00   居家清凉
  其余时间        便服

想让她穿指定的，四个地方都能改：

  · 右键桌宠 → 换装（一排图标，点一下即固定）
  · 对话框上方的「👗 当前穿着」按钮 → 弹出全部 24 套
  · 对话框旁边的立绘小窗 → 点立绘本体
  · 设置 → 桌宠外观 → 换装

对话框上那个「🪟」按钮是单独用来显示/隐藏旁边的立绘小窗的
（之前它和换装挤在一个按钮上，把换装功能挤没了）。

选一套就固定在那一套，不再随时间自动切换；点「跟随时间」恢复自动。
四处读写的是同一份设置，改哪边都同步。

她还会自己换：挂机轮换时会连衣服一起换，这部分随亲密度解锁 ——
刚认识时只有便服，到「形影不离」才会解锁全部 24 套。
算上动作和衣服，她的挂机表现从 4 种增长到 39 种，
而且每一种都会真的轮到（白天深夜都一样）。

气泡平时显示今天的摸鱼收入；她说话时会短暂切换成台词，
说完自动回到收入显示。表情同理，几秒后自动回到当前状态的样子。

不想被她打扰的话，「设置 → 桌宠外观 → 互动」里可以逐项关掉。

### 表情一览

她会根据状态和你的操作换姿势，一共 24 种：

  站姿       还没开工
  在笑       今日已赚满
  在歇着     休息日
  趴着发呆   挂机太久、午后犯困
  看书       摸鱼进行中（工作状态）
  害羞       被摸头的时候
  生气       被戳太多次
  惊讶       双击吓到
  比心       打招呼
  思考       在等你想说什么
  摊手       下班了
  竖大拇指   打卡成功
  拍手       完成一轮摸鱼
  点头       表示认同
  伸懒腰     坐久了舒展一下
  吃零食     摸鱼时偶尔吃两口
  戴耳机     挂机时听歌
  递咖啡     提醒你起来动一动
  打哈欠     早上刚开工 / 深夜
  睡觉       深夜
  高兴       心情好的时候
  笑得很开心 聊到开心的事
  有点难过   聊到难过的事
  挥手       退出前跟你告别

挂机时她会自己在「吃零食 / 戴耳机 / 思考 / 打哈欠」之间换姿势，
看起来像在旁边做自己的事；深夜和清早会优先打哈欠、想睡觉。

### 亲密度

每次互动都会累积亲密度，从「有点眼熟」一路到「形影不离」共 5 档：

  有点眼熟 → 熟络起来了 → 好朋友 → 默契搭档 → 形影不离

怎么涨：

  和她聊天，一条消息 +2，聊完一轮再 +3（每天最多 60 点）
  长按贴贴 +2      双击 +2      单击 +1      每天见面 +1

聊天是涨得最快的一条路；每天的聊天得分有上限，聊到顶了当天不再涨，
摸头双击照样算。上限是为了让关系是「处」出来的，而不是一晚上刷满。

关系变近她会真的不一样，不只是数字变大：

  · 说话方式变了：熟络之后句首会带「诶，」，最熟时不再说客套话
  · 主动找你的次数变多：最熟时比生疏时勤快不少
  · 挂机台词更亲近：会主动讲自己的事、说「我一直在的」这类话

进度条在三个地方都能看到：

  右键桌宠        亲密度面板（档位、距升级、今日聊天得分）
  对话窗标题栏    Yuki 名字下面那条，聊天时实时涨
  面板侧边栏      点左下角等级徽章展开，和摸鱼等级并列

升级时对话窗会浮出一个「关系升级 · 好朋友」的提示。
「设置 → 桌宠外观 → 互动」里可以关掉亲密度统计，也有「重置亲密度」按钮。

右键菜单一共有 8 项：

  ✅ 立即打卡        当天没打卡时可用，点了变成「✓ 今日已打卡」
  💭 对话            弹出 AI 对话窗（需要先配 API Key，见下）
  📊 打开摸鱼面板    打开完整面板窗口
  💬 隐藏 / 显示气泡  收起或展开头顶的收入气泡
  🔍 放大显示        每次 +10%，最大 200%
  🔎 缩小显示        每次 -10%，最小 60%
  ↺ 恢复默认大小     一键回到 100%
  ✕ 退出摸鱼桌宠     彻底关闭程序

菜单里还有一条亲密度进度条，实时显示当前档位和距下次升级还差多少。
菜单项右侧会实时显示当前状态（收入金额、缩放百分比等）。


三、AI 对话（可选功能）
-----------------------

不受限制也能用，配置一次即可。

1. 去 https://platform.deepseek.com 注册并创建一个 API Key（形如 sk-xxx）
2. 打开「设置 → AI 对话」
3. 服务商选「DeepSeek 官方」，把 Key 粘进 API Key 框
4. 点「测试连接」，显示「连接正常」就可以用了

之后右键桌宠选「对话」，或点面板侧边栏的「AI 对话」，
就会弹出聊天窗口：

· Enter 发送，Shift+Enter 换行
· 回复是流式逐字出现的，生成过程中可以点 ■ 停止
· 点右上角 ☰ 看历史对话，可切换、重命名（✎）、删除（🗑）
· 点 ＋ 新建对话
· 对话记录存在本机，重启后还在

### 角色设定

「设置 → AI 对话 → 角色设定」可以切换：

  Yuki（默认）        女大学生，活泼开朗，不黏人
  女友（黏人型）      会撒娇、会关心你、记得你说过的事
  学习助手（掩护模式）正经工具口吻，防同事瞄屏
  通用助手            中性回答

Yuki 是把你当朋友的：会分享自己今天干了什么（早八、食堂、赶作业），
你忙的时候不会追问，聊天是分享而不是索取。

### 她知道现在几点

她会拿到当前的真实时间（几点、星期几），所以作息和现实对得上：

  早上 8 点    刚起床、赶早八，不会说要去吃午饭
  上午 10 点   在上课或做作业
  中午 12 点   在食堂或点外卖
  下午 3 点    在上课、赶作业、改图
  傍晚 6 点    刚下课或准备晚自习
  晚上 9 点    在宿舍写作业、刷手机、追剧
  深夜 1 点    早就该睡了，如果还醒着就是在熬夜赶作业

同时它也知道你的作息：工作日会记得「他在上班，别拉他出去玩」，
休息日则「别问他工作上的事」。

她确实知道现在是几点、周几 —— 你直接问她就行，她会照实回答
（「现在下午三点多啦」「都周一了」）。

这两条修的都是真实问题：之前她不知道时间，会在早上九点多说「我去吃午饭了」；
后来时间给了她，但没告诉她「你确实知道」，于是被问几点时又含糊其辞。

### 她能看图了

对话框左下角有个 📎 按钮，可以给她发图片。三种方式都行：

  · 点 📎 选本地图片
  · 直接 Ctrl+V 粘贴截图（最顺手 —— 截完图直接粘）
  · 把图片文件拖进对话框

发之前能看到缩略图，点 ✕ 可以移除，一条消息最多 4 张。
她可以描述图片、读截图里的文字、分析图表。

图片会自动压到长边 1280 再发，不用手动处理大小。

需要先换个模型：默认的 deepseek-chat 是纯文本模型，看不懂图。
去「设置 → AI 对话 → 模型」把它改成 deepseek-flash（原生多模态），
然后点「保存」。改完再发图就不会报错了。

（如果忘了改，发图时会直接提示你怎么改，不会让你对着报错猜。）

### 她认识自己

把你的立绘发给她，她会认出来那是自己 —— 不会当成陌生人。

她知道自己长什么样：棕色长卷发、齐刘海、红棕色眼睛，常穿白色针织裙。
这是通过两种方式告诉她的：一段外貌描述，外加一张她自己的参考图
（她真的「看过」自己一次，所以认得更准）。

她把「不像自己」的图也分得清 —— 你发别的角色或网图，她不会硬认成自己。

（参考图只在模型支持看图时注入。所以这条也依赖 deepseek-flash。）

### 自己写人设

内置人设不能直接改，但可以复制一份随便改：

1. 「设置 → AI 对话 → 角色设定」，选中你想改的人设
2. 点「复制」——会连提示词一起复制成副本，并自动切到副本
3. 这时会出现「编辑」「删除」按钮，点「编辑」打开文本框
4. 改完点「保存」即时生效

点「新建」可以从空白开始写。建议写清这几块，模型才不容易跑偏：

  身份      你叫什么、是谁、和用户什么关系
  性格      活泼/安静、爱不爱开玩笑
  说话方式  长短、语气词、要不要用 emoji
  绝对不要  「不要自称 AI」「不要总结式收尾」这类硬约束

删除正在使用的人设会自动切回 Yuki，不会让你卡在空白设定上。

### 节假日和调休

程序会自动识别中国的法定节假日和调休补班日：

  🎉 国庆节         自动算成休息日，收入不计算
  🔁 中秋节前补班   周日也要上班，正常计算收入

侧边栏的摸鱼进度卡上会显示当天标签。
首次运行需要联网拉一次节假日表，之后缓存 7 天；
拉不到也不影响使用，只是退回「只看周末」的判断。

### 让它记得更多（长上下文）

「设置 → AI 对话」里有两项：

  上下文条数          默认 100 条（最大 400）
  上下文长度上限      默认 48000 字符（约 3 万汉字）

两个一起生效，聊天聊得越久越能记住前文。
不要设太满——DeepSeek 上限约 64K token，留点余量给它自己的回复。

顺带一提，人设本身也占额度：女友人设 800 多字，
所以实际可用历史 ≈ 上限 − 人设长度。程序会自动把这块扣掉。

不想花钱的话，服务商可以选「本地 Ollama」，
地址填 http://127.0.0.1:11434/v1，这样就完全离线、零成本。

注意：API Key 只存在你自己电脑的数据库里，程序不会把它发给任何第三方。

### 测试连接成功但对话还是不行？

到「设置 → AI 对话」点右边的「全链路自检」按钮，
它会把每一步摊开显示，一眼看出卡在哪：

  ✓ 读取设置 / 配置校验 / API Key   本地环节
  ✓ 非流式请求                      相当于「测试连接」
  ✓ 流式请求                        真正的对话路径
  ✓ 流式增量回调                    逐字输出是否工作
  ✓ 数据库读写                      存不存得进去

注意「测试连接」只发一次短请求，而真实对话走 SSE 长连接，
两者是不同路径。如果自检里「非流式请求」通过、但「流式请求」失败，
基本可以确定是代理 / 公司防火墙 / 杀毒软件拦了流式响应
（现象就是 AI 一直不回复）。

把自检那一整块截图发出来就能定位。


四、面板有什么
--------------

点托盘图标，或右键桌宠选「打开摸鱼面板」。

主页        今日摸鱼收入（逐秒实时进账）、等级、快捷打卡
摸鱼研究院  工作性价比计算器 + 生命电量
打卡记录    月历打卡视图
设置        工作时间、薪酬、月休、发薪日、桌宠外观

左侧栏底部就是打卡按钮和摸鱼进度卡，收起侧栏后只留图标。


五、第一次使用要先设置
----------------------

进入「设置 → 工作与薪酬」，填四项：

  月薪        税前月薪
  上下班时间  默认 09:00 - 18:00
  每日休息    午休等不计薪时长，默认 2 小时
  月休方式    双休 / 单休 / 大小周 / 不定休
  发薪日      每月几号发工资

填完点「保存」，首页和桌宠立刻按新数据计算。


六、摸鱼收入怎么算
------------------

  日薪     = 月薪 ÷ 本月工作日数
  今日收入 = 日薪 × 今天已经过去的计薪工时占比

工作日数按真实日历算（双休的月份可能是 20~23 天不等），
所以每个月日薪会略有差异，这是对的。

休息日显示「今日休息」，收入为 0。

四种状态：尚未开工 → 摸鱼进行中 → 今日已赚满 / 今日休息


七、打卡
--------

每天只能打卡一次，重复点不会重复计数。
摸鱼天数 = 累计打卡天数，等级按天数升，一共 7 级：

  0 天 职场萌新 → 3 天 初级摸鱼人 → 7 天 摸鱼学徒 → 30 天 资深摸鱼人
  → 90 天 摸鱼大师 → 180 天 摸鱼宗师 → 365 天 摸鱼之神

### 漏打了怎么补（入职后一直没打卡的看这里）

场景：你 7 月 14 日就上班了，但之前没打卡，现在想一次性补齐。

面板 →「打卡记录」，右下角有一张「漏打补卡」卡片：

1. 点它展开，把「开始日期」改成入职那天（比如 2026-07-14）
2. 下面立刻列出会补哪几天——只补工作日，周末和法定假日自动跳过，
   调休补班日会照常补上并标出来
3. 确认天数没问题，点「确认补 ×× 天」
4. 补完日历自动跳到起始月，你能直接看到结果

两个细节：

· 它只补一次。已经打过卡的日子会自动跳过，重复点不会算出双份。
· 连续打卡按工作日算。周五和周一都打了卡，连着算 2 天，
  不会因为中间隔了个周末就断掉（但工作日中间缺一天仍会正常断档）。

想撤销就只能删数据库了（见第十节），所以点确认之前先看清楚预览。


八、上班怕被看见
----------------

设置 → 桌宠外观 → 打开「偷偷摸摸模式」，
界面文案会换成学习风格（「今日摸鱼收入」变「今日学习进度」，
品牌名变「Study Desk」），看起来像个正经的学习工具。


九、找不到桌宠了怎么办
----------------------

桌宠关掉之后程序还在后台跑，随时能叫回来。

最稳的办法：看右下角托盘区（时钟旁边的小图标），
如果没看到小猫图标，点一下那个向上的小箭头「^」展开溢出区，
里面就有「摸鱼桌宠」。找到后：

  · 单击托盘图标    直接把桌宠叫回来
  · 右键托盘图标    菜单里选「找回桌宠」或「全部显示」

面板窗口开着的话，左下角也有「显示桌宠」按钮，
按钮是虚线框就说明桌宠当前是隐藏的。

如果托盘图标被系统藏了，可以固定它：
  设置 → 个性化 → 任务栏 → 其他系统托盘图标 → 把「摸鱼桌宠」打开

注意：「退出摸鱼桌宠」是真的关闭程序，那个要用开始菜单或桌面图标重新启动。


十、数据存在哪
--------------

%APPDATA%\desk-pet\desk-pet.db

一个本地 SQLite 文件，纯离线，不联网、不上传。
想备份就复制这个文件，想清空就删掉它（下次启动会重建）。


十一、常见问题
------------

Q: 双击没反应？
A: 看右下角托盘区，程序可能已经起来了。托盘图标右键 → 打开摸鱼面板。

Q: 桌宠不见了？
A: 单击右下角托盘的小猫图标就会回来（图标被系统藏了就点「^」展开）。
   或右键托盘图标 →「找回桌宠」。详见第九节。

Q: 提示找不到 VCRUNTIME140.dll 之类？
A: 装一下微软 VC++ 运行库（Microsoft Visual C++ Redistributable x64）。

Q: 杀毒软件报警？
A: 未签名的 Electron 程序常见误报。加信任即可，程序不联网。
